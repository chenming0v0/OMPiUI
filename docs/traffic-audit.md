# 流量审计

入口：应用设置 → 流量审计。Web、桌面和 Android 使用同一套采集逻辑，不依赖升级后端。

## 范围与口径

- 只统计当前客户端经应用传输层发起的后端 HTTP 请求，以及事件流、终端流的 WebSocket 消息。
- 每次 HTTP 重试独立成条；WebSocket 连接尝试与消息分开记录，支持按服务器、协议、方向、URL、事件、会话和失败状态筛选。
- 提交大小是交给传输层的请求正文大小，不表示服务器已收到全部数据。网络失败不能据此认定写请求没有执行。
- 接收大小是业务通过 `json()`、`text()`、`arrayBuffer()` 或 `blob()` 读取的正文大小；不提前读取响应。未读取的正文、未支持的正文类型显示 `?`，不当成已接收的零字节。
- 字符串按 UTF-8 计量。JSON 中重复出现的消息字段按实际序列化大小计入，不根据最终显示的文本大小推算。
- HTTP 响应头耗时和正文读取完成耗时分开保存；WebSocket 连接行的耗时是握手等待或连接存续时间，不是消息的端到端延迟。
- `Content-Length`、`Content-Encoding` 作为独立元信息保存。应用正文一般已经解压，不用声明长度覆盖读取字节数。
- 不包含静态资源、其他客户端、HTTP 头、WebSocket 帧头、TLS、穿透协议开销和网络重传，因此不是穿透服务计费流量。直接消费响应流、克隆响应或 `formData()` 读取未纳入正文计量。

## 保存与隐私

- 默认开启计量、关闭正文预览；暂停不清空已有记录，已经发起的 HTTP 请求仍会更新完成状态。
- 保留最近 2000 条记录，超过上限淘汰最早明细；累计统计仍保留已淘汰记录的已计量字节。界面每页最多展示 50 条。
- 数据只留在客户端内存，刷新或退出后清空。关闭设置页不停止采集，也不继续进行界面刷新。
- 开启预览后，只保存限长摘要，遮蔽常见 token、API key、密码、cookie、配对码等结构化字段和 URL 参数。不保存鉴权请求头，也不保留网络错误中的原始正文。
- 深度、节点数量、数组长度和字符串长度都有上限。大体积或无法解析的请求 JSON 不保存原始片段，避免从不完整 JSON 中泄漏凭证。
- 脱敏不能识别所有自由文本中的秘密，预览仍可能含会话、文件、工具输出或终端内容。分享前检查导出。
- 关闭预览会移除保留记录中的预览，不会为已经发起的请求重新启用预览。
- 导出包含全部筛选明细，不仅是当前页；累计统计针对选定服务器，排行仅针对仍保留且符合筛选条件的记录。

## 接入位置

- `packages/app/src/omp/trafficAudit/`：计量、限量存储、预览脱敏和汇总。
- `piFetch`：后端业务 HTTP 请求；健康检查及配对兑换的直接请求另外接入相同采集层。
- `openPiSocket`：浏览器原生 WebSocket 与 Tauri Rust 桥共享的包装层。
- 事件流和终端消费方复用已经解析的对象标注事件类型，不重复解析接收帧，也不改变业务消息、重试、订阅或正文读取顺序。
- 暂停时跳过新请求及消息的采集；高频字符串计量复用 64 KiB 缓冲，通知订阅者的频率限制为每 500 ms 一次。
