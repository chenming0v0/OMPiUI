# 0.6.22 网络修复验收

本批逐项复核 GitHub #84 至 #140，共 57 项。结论及逐条评论原文数据见
`network-issue-resolutions.json`。#92、#93、#100、#102 的故障前提不成立，
按复核结论关闭；其余项目处理成立的部分，并在评论中说明重复根因及范围。

## 协议与部署

本批使用协议 2 和 `ompiui.events.v2`。主消息增量块、附件引用、轻量平铺树、
进度字段增量和 checkpoint 完整性标记需前端、服务端及 worker 配套升级。
官方 OMP 会话文件格式、目录与继续写入方式不变；浏览和刷新不创建写 runtime。

## 后端预览

`preview.settings.get` / `preview.settings.set` 读写后端数据目录的
`preview-settings.json`。`subagentThinking` 默认关闭，修改后立即影响所有客户端
的实时预览与磁盘回填。完整子会话界面依然读取完整思考内容。
预览过滤以完整 JSONL 行为单位，`nextByte` 始终是原文件的字节位置。

## 有界阅读

历史窗口最多 400 条或 8 MiB，较早历史可继续向前读取，亦可返回最新。
大图片在历史页中仅传引用，点击时分片加载。树导航只传位置、标签及短预览，
前端保留原来的拓扑与导航语义。原始文本和图片不在磁盘中截断或改写。

## 验证记录

- 新增用例验证主文字及工具字符串参数的增量无损还原、思考开关持久化、
  预览过滤不改原文件、JSONL 追加及替换、大图引用、深树平铺序列化、
  历史窗口，以及 relay 配额等待时结束标记不越过正文。
- 相关 Node 与前端回归覆盖连接、订阅、413、游标、Git、文件搜索、跨进程 IPC、
  子会话查找与恢复；Rust 桥编译通过。
- 针对回归发现修复较旧 checkpoint 回退游标及提前关闭连接吞掉 413 的时序。
- 线上负载、设备长期锁屏及安装包实机升级不以源码用例或发布构建冒充验收。
